# Web app live evidence: Phase W0 on the work pair, 2026-11-09

Measured against the served web app on the work pair's serving host (host-c), built from beads-ui `main` at `49e9c5b`, over loopback, by the build coordinator at 13:29 UTC. Every request below used a real browser session obtained through the one-time sign-in link and its exchange, except where the check is that no session exists. Writes targeted an issue id that does not exist, so a check that failed open could still change nothing. The test session was revoked at the end and the listing then showed no browser sessions.

| Check (T-W0.1 unless named) | Request | Expected | Observed |
|---|---|---|---|
| Sign-in exchange | one-time link, `Sec-Fetch-Site: none` | redirect with a session cookie | 303 |
| Signed-in read | `GET /api/board` with the cookie | 200 | 200 |
| Cross-site write | `POST /api/issues/<id>/priority` with the cookie, `Origin: https://evil.example`, `Sec-Fetch-Site: cross-site`, the write header | refused | 403, "a write from Sec-Fetch-Site: cross-site is refused" |
| Write without the write header | same-origin `POST` with the cookie, no `X-Beads-UI` | refused | 403, "a write needs the X-Beads-UI header" |
| Control: a well-formed same-origin write | same-origin `POST` with the cookie and the header, body missing a field | reaches validation | 400, "a priority write needs `priority` (0 to 4) and `shown`" |
| Forged identity header | `GET /api/board` with only `Tailscale-User-Login`, no cookie or token | refused | 401 |
| Foreign Host header | `GET /api/board` with the cookie and `Host: evil.example` | refused | 403 |
| Revoked session | `GET /api/board` with the revoked cookie | refused | 401 |
| `/healthz` without a session (T-W3.2) | `GET /healthz`, no cookie | 200 or 503 | 401 at this commit; the W3 leg makes it a public status-only route |

The control row is what makes the two 403 rows evidence: the same request with the header present reaches body validation, so the refusals come from the origin and header checks, not from a missing route or a bad body.
